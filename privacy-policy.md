# Arthur – Privacy Policy

*Last updated: October 31, 2026*

Arthur is a private assistant that accesses only its owner's own Google Calendar and Google Tasks data. It uses that data only to show, add and update the owner's events and tasks on request. The data is processed only on the owner's own computer and is never sold or shared with anyone. It is kept only as long as needed to complete each request. Arthur's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Questions: please open an issue in this repository's issue tracker.
